# JEV 儀表板：匯出 Excel／CSV（設計）

日期：2026-10-12

前提：[主 spec](2026-09-23-jev-dashboard-design.md)、[登入與唯讀分享 spec](2026-10-01-auth-sharing-design.md)（下稱「唯讀分享 spec」）、[儀表板篩選器 spec](2026-10-07-dashboard-filters-design.md)（下稱「篩選器 spec」）、[KPI spec](2026-10-07-kpi-card-design.md)。本文件只寫這次改變的部分。

## 1. 問題

每張圖的數字現在只能在畫面上看，要拿去做簡報或跟別的報表核對，只能手抄或截圖。明細表在畫面上也只顯示前 500 筆。backlog「補齊」P2：每張圖背後的數字和明細表都能下載（比照 Power BI、Tableau 的匯出資料）。

## 2. 規則

### 2.1 匯出什麼

- 一次匯出一張卡，一張卡一個檔案。
- 資料跟畫面上這張卡相同：套用同一組篩選（包括檢視者臨時改的），表頭用顯示名稱。內容就是 `/data` 裡這張卡的 `dimensions` 和 `rows`，列的順序不變。
- 各種卡：
  - 長條、折線、圓餅、堆疊長條、熱力圖、雷達圖：匯出圖上的彙總數字。有系列的圖照 `/data` 的長表格式，每個組合一列（例如「月份、地區、營收」三欄），不轉成交叉表。
  - 散佈圖：每個點一列（x、y 兩欄）。`/data` 本來就不截斷，跟畫面一樣不設上限。
  - 明細表：表上的欄位，而且是全部的列，不受畫面 500 筆的限制。
  - KPI 卡：`/data` 回傳的已結束期別，最多 13 期，分成期別、數值兩欄。
- 不匯出的內容：異常標註、比率期間的說明、「沒套用篩選」的說明、標題以外的卡片設定。

### 2.2 檔案格式

**Excel（.xlsx）**

- 只有一個工作表，名稱固定為「資料」。第 1 列是表頭（粗體），資料從第 2 列開始。
- 數字存成數字格。文字、日期、期別存成文字格，寫法跟畫面相同（日期 `2026-09-24`、月 `2026-09`、季 `2026-Q3`）。文字格不會被 Excel 當成公式執行，補零的代碼也不會掉 0。
- 比率卡（`/data` 的 `percent` 是 true）的最後一欄是比率值，用百分比格式 `0.0%` 顯示，存的還是小數，例如存 0.043、顯示 4.3%。
- 空值留空白格。
- 超過 Excel 上限（1,048,575 列資料）時不產生檔案，回 400「資料超過 Excel 的列數上限（1,048,575 列），請改下載 CSV」。
- 用 POI 的 `SXSSFWorkbook` 邊寫邊送，明細表很大時也不必把整份檔案放在記憶體裡。

**CSV**

- 編碼用 UTF-8，開頭加 BOM，Excel 直接打開時中文才不會變成亂碼。逗號分隔、CRLF 換行，用 commons-csv 的 `CSVFormat.EXCEL`。
- 數字用一般寫法，不用科學記號，整數不帶 `.0`（1200.0 寫成 `1200`）。比率寫小數（0.043），不加 %。
- 文字以 `=`、`+`、`-`、`@`、Tab、CR 開頭時，前面加一個 `'`，免得 Excel 把它當成公式執行（CSV injection）。數字格是負數時照寫，不加 `'`。
- 空值寫空字串。
- 不設列數上限。

**檔名**

- `<卡片標題>.xlsx` 或 `<卡片標題>.csv`。標題用畫面上的標題，也就是套過顯示名稱的那個。
- 拿掉 Windows 檔名不能用的字元（`\ / : * ? " < > |` 和控制字元），去掉頭尾空白，最多 100 字，什麼都不剩時改用「圖表」。
- 回應帶 `Content-Disposition: attachment; filename*=UTF-8''…`，中文檔名才不會亂碼。

### 2.3 誰可以匯出

- 擁有者，以及看得到這份儀表板的登入帳號（被分享的帳號、用公開連結打開的帳號）。這些人本來就看得到同樣的資料，分享對話框也寫明「包括明細表和敏感欄位」。
- 沒登入的訪客不能匯出：卡片上沒有下載鈕，直接打 API 會拿到 401。原因有兩個：沒登入的請求目前沒有次數限制（backlog P2），而匯出明細表又要讀整份來源。
- 檢視者的篩選限制跟 `/data` 一樣（篩選器 spec 2.3），不能用的分類篩選不生效。
- 來源載入失敗時，檢視者看到的錯誤一樣換成通用訊息（唯讀分享 spec 4.5）。

### 2.4 不能匯出的時候

- 製圖頁的預覽不能匯出。儀表板存檔之後，卡片才有下載鈕。
- 卡片有錯誤（欄位遺失、不是日期、來源載入失敗、來源已刪除、已停止分享），或一列資料都沒有（KPI 卡則是一期都還沒結束）時，畫面上沒有下載鈕。有錯誤的卡片直接打 API，回 400「這張圖目前沒有資料可以下載」；沒有資料的卡片直接打 API，會拿到只有表頭的檔案。

## 3. API

`GET /api/dashboards/{id}/charts/{chartId}/export?format=xlsx&filters=…`

| 參數 | 說明 |
|---|---|
| `format` | `xlsx` 或 `csv`；其他值回 400「format 只能是 xlsx 或 csv」 |
| `filters` | 跟 `/data` 一樣，是 URL 編碼過的 JSON；沒帶就不篩選 |

- 成功時回傳檔案本身：xlsx 的 Content-Type 是 `application/vnd.openxmlformats-officedocument.spreadsheetml.sheet`，CSV 是 `text/csv; charset=UTF-8`，都帶 2.2 的 `Content-Disposition`。
- 錯誤跟其他 API 一樣回 JSON：
  - 沒登入：401。`SecurityConfig` 不用改，免登入的規則只放行 `/{id}`、`/data` 和 `/filter-options`。
  - 看不到這份儀表板：404（`DashboardService.view`）。
  - 儀表板裡沒有這個 `chartId`：404「找不到這張圖」。
  - 卡片有錯誤（2.4）、超過 Excel 上限（2.2）：400。
- 每次匯出都重新載入這張卡的來源，外部 API 也會再抓一次。不沿用 `/data` 的結果，也不寫進異常檢查的暫存（`recent`）。

## 4. 後端

- `UniversalTransformer.transform` 加一個選項，讓明細表不截斷；`TABLE_ROW_LIMIT` 只用在畫面，其他圖型不受影響。
- `DashboardDataService.exportData(userId, config, chartId, filters, denied)`：只拿這一張卡跑既有的 `build`，所以只會載入它的來源。套上顯示名稱（`relabelled`）後回傳一張 `ChartData`，不寫 `recent`。
- 新增 `ChartExport`，只有靜態方法：`xlsx`、`csv`、`filename`，以及 CSV 的公式字元處理。檢查列數有沒有超過 Excel 上限的部分要拆成可以單獨測的小函式。
- `DashboardController.export`：跟 `data` 一樣，用 `service.view` 查權限、算 `denied`，檢視者的錯誤換成通用訊息。所有檢查都在開始寫檔之前做完，檢查過了才設定標頭，直接寫進回應。

## 5. 畫面

### 5.1 卡片

- 標題列多一個下載鈕，放在「設定」和「✕」左邊。圖示用 `mdi-download`，size small、density default，樣式跟「設定」「✕」一樣（`tc-remove`）。aria-label 和 title 都是「下載這張圖的資料」。
- 按下去跳出選單（`v-menu`），有兩個選項：「Excel（.xlsx）」、「CSV」。
- 選好後，下載鈕在等待時顯示 loading 並停用。`grid-layout-plus` 的 `dragIgnoreFrom` 預設是 `a, button`，按下載鈕不會拖動卡片。
- 下載鈕只在這些條件同時成立時出現：已存的儀表板（不是預覽）、不是訪客、卡片有資料（沒有 `error`，`rows` 不是空的）。

### 5.2 元件之間

- `ChartCard` 多一個 prop `download`，型別是函式，參數是格式，回傳 Promise。有這個 prop 才顯示下載鈕，等待中的狀態由卡片自己管理；做法跟 `KpiForm` 的 `save` 一樣。
- `DashboardView` 多一個 prop `guest`，App 的訪客檢視傳 `true`。不是預覽也不是訪客時，`DashboardView` 才傳 `download` 給每張卡。
- `DashboardView` 的下載函式帶著目前的篩選（`filters`，包括臨時改的）呼叫 API，再用 `URL.createObjectURL` 加 `<a download>` 存檔。檔名從 `Content-Disposition` 的 `filename*` 讀，讀不到就用卡片標題。
- 下載失敗時，訊息顯示在儀表板最上面原本那條錯誤提示（`error`），例如「下載失敗：資料超過 Excel 的列數上限（1,048,575 列），請改下載 CSV」。401 照 `api.js` 原本的方式跳出重新登入。
- `api.js`：`request` 多一種回傳原始 Response 的方式，錯誤處理（401、錯誤訊息）沿用原本的；另外新增 `exportChart(id, chartId, format, filters)`。

## 6. 測試

後端：

- `ChartExport`：
  - xlsx 的數字格和文字格，補零代碼 `007` 保持文字；表頭是粗體；比率用百分比格式；空值是空白格。
  - CSV 開頭有 BOM；數字寫法（1200.0 寫成 `1200`，很小和很大的數字都不用科學記號）；公式字元加 `'`，負數的數字格不加；空值寫空字串。
  - 檔名：拿掉不合法的字元、空標題改用「圖表」、超過 100 字截斷。
  - 超過 Excel 上限的判斷單獨測，不用真的產生一百萬列。
- `UniversalTransformer`：用不截斷的選項時，501 列全部回傳；畫面用的照舊回 500 列。
- `DashboardDataService.exportData`：有套篩選和顯示名稱；只載入這張卡的來源；不寫 `recent`；檢視者的 `denied` 不生效。
- controller（MockMvc）：
  - 擁有者和被分享的帳號都下載得到；沒登入回 401；沒有權限回 404。
  - `chartId` 不存在回 404，`format` 不對回 400，卡片有錯誤回 400。
  - Content-Type 和 `Content-Disposition`（中文檔名）正確。

前端：

- `ChartCard`：
  - 有 `download` 時才有下載鈕；卡片有錯誤或沒資料時沒有。
  - 選單的兩個選項分別呼叫 `download('xlsx')`、`download('csv')`；下載中按鈕停用。
- `DashboardView`：預覽和訪客不傳 `download`，已存的儀表板（擁有者、檢視者）有傳；下載時帶目前的篩選；失敗時顯示錯誤。
- `api.js`：下載成功時回傳 blob 和檔名；失敗時回傳錯誤訊息；401 會觸發 `unauthorized`。

瀏覽器（自己用 Chrome 操作）：

1. 擁有者打開一份有長條圖、明細表、KPI 卡和比率圖的儀表板，每張卡各下載 Excel 和 CSV，再把檔案讀出來核對：表頭是顯示名稱，數字跟畫面一致，比率在 Excel 裡顯示成百分比。
2. 明細表的來源超過 500 列：畫面寫「僅顯示前 500 筆」，下載的檔案有全部的列。
3. 選好篩選再下載：檔案裡只有篩選後的資料。
4. 有補零代碼欄位（例如 `007`）的明細表：Excel 檔裡還是 `007`。
5. 被分享的帳號登入後下載得到；訪客打開公開連結時沒有下載鈕。
6. 製圖頁的預覽沒有下載鈕。

## 8. 決定（2026-10-12）

| 題目 | 選擇 | 沒選的 |
|---|---|---|
| 格式 | Excel 和 CSV 都有，後端產生 | 只有 CSV、前端產生；只有 Excel |
| 誰能匯出 | 擁有者和看得到的登入帳號 | 能看就能匯出（包括訪客）；只有擁有者 |
| 範圍 | 每張卡各自下載 | 加上整份儀表板匯出成一個 Excel |
| 圖表卡的內容 | 圖上的彙總數字 | 彙總數字加上原始資料列 |

## 9. 不做

- 整份儀表板匯出成一個檔案（每張卡一個工作表）。
- 圖表卡附上原始資料列。這屬於 P3 的「下鑽」。
- 從製圖頁的預覽匯出。
- 讓沒登入的訪客匯出。等「沒登入的 API 呼叫次數限制」做完之後再考慮。
- 日期存成 Excel 的日期格。現在存成文字，照字串排序的結果是對的，只是 Excel 篩選時沒有年、月的樹狀選單。
- 把有系列的圖轉成交叉表（月份當列、地區當欄）。
- 匯出圖片或 PDF。那是另一項「匯出 PDF 與定期寄送」。
- 在檔案裡寫篩選條件、資料來源或匯出時間。
