# JEV 儀表板：儀表板篩選器（設計）

日期：2026-10-07

前提：[多來源 spec](2026-09-27-multi-source-dashboard-design.md)、[登入與唯讀分享 spec](2026-10-01-auth-sharing-design.md)（下稱「分享 spec」）、[比率期間對齊 spec](2026-09-29-ratio-period-alignment-design.md)。本文件只寫這次改變的部分。

## 1. 問題

每張圖的範圍是固定的。想看「北區」或「上季」，只能重新分析一次。backlog「補齊」P2：整份儀表板共用分類篩選和期間，選了之後每張圖一起變（參考 Grafana 的 variables 與時間範圍）。

## 2. 規則

### 2.1 篩選的種類

- 期間：一個下拉選單，選項是「不限、本月、上月、本季、上季、今年、去年」。
  - 都是日曆上的整段：本月是這個月 1 日到月底，本季是這一季第一天到最後一天，以此類推。「今天」用後端的 `Clock`（`JevConfig.clock()`）。
  - 本月、本季、今年包含還沒到的日子，資料裡有未來日期（例如預計出貨日）也算進去。
- 分類：最多 3 個，每個選一個欄位和一個以上的值，例如「地區：北區、南區」。
  - 同一個分類裡的值是「或」，不同分類之間、分類和期間之間是「且」。
  - 只能選文字欄位。整份儀表板加起來相異值超過 200 個的欄位不列（例如備註、客戶名稱）。
  - 值是空的列歸在「（空白）」（`UniversalTransformer.BLANK`，分組空值那次修正加的），可以選。

### 2.2 篩選套到哪些圖

- 篩選在轉換之前作用在資料列上，比率、對照、兩個數值的圖都照原本的算法，只是資料列變少了。比率的期間對齊用篩選後的資料列算。
- 分類篩選照畫面上的欄位名稱比對：在每張圖的來源裡，找顯示名稱（沒有就用欄位名稱）跟篩選欄位一樣的那個欄位。不同來源的 `region` 和 `地區`，只要顯示名稱都設成「地區」，就會一起篩。同一個來源裡顯示名稱不會重複（`setLabels` 已經擋了）。
- 期間篩選用的日期欄位：
  - 卡片有 `timeGrain` 時，用它的 `x`。
  - 沒有時，用來源的第一個日期欄位（schema 順序，跟比率期間對齊的 `dates` 一樣）。
  - 日期是空的列，在選了期間時不算進去。
- 卡片的來源沒有對應的欄位（分類找不到同名欄位、期間找不到日期欄位）時，那個篩選對這張圖不生效，其他篩選照樣生效。回傳的資料標出哪些沒生效，卡片下面寫出來（6.4）。
- 只套用在已存的儀表板。製圖頁的預覽不篩選。

### 2.3 存成預設

- 擁有者可以把目前的篩選存成這份儀表板的預設。打開儀表板時一律套用預設；沒存過就是不篩選。
- 任何能看這份儀表板的人，包括唯讀檢視者和沒登入的訪客（如果之後做了免登入），都能臨時改篩選。臨時的篩選不存檔，不影響別人，重新打開又回到預設。

### 2.4 異常標註

- 異常檢查照篩選後的資料判斷（使用者選，2026-10-07），標註跟畫面上的數字一致。
- 每換一組篩選，就會多問一次 JEV；同一組篩選的結果由 `HighlightService` 現有的快取接住（key 裡有送給 JEV 的摘要，篩選後的摘要不一樣，就是不同的 key）。
- 「已結束的期間」規則不變。選了「本月」時資料只有進行中的這一期，比不出來，就不標註。

## 3. 篩選的資料格式

```json
{
  "period": "last_quarter",
  "fields": [
    { "field": "地區", "values": ["北區", "南區"] }
  ]
}
```

- `period`：`this_month`、`last_month`、`this_quarter`、`last_quarter`、`this_year`、`last_year`，或 null（不限）。
- `fields`：可以是空陣列或 null。`field` 是畫面上的欄位名稱（2.2）。
- 驗證（存預設和查詢參數共用，違反時 400）：
  - 「期間只能是 本月、上月、本季、上季、今年、去年」。
  - 「分類篩選最多 3 個」。
  - 「篩選的欄位名稱不能空白」，最多 50 字：「篩選的欄位名稱最多 50 個字」。
  - 「同一個欄位只能篩選一次」。
  - 每個欄位至少 1 個、最多 200 個值，不能是 null，每個最多 200 字：「每個篩選要選 1～200 個值」「篩選的值最多 200 個字」。
  - 查詢參數不是合法的 JSON：「篩選的格式不對」。

## 4. API

- `GET /api/dashboards/{id}`：設定多一個 `filters`（3 的格式），沒存過就沒有這個欄位。
- `PUT /api/dashboards/{id}`：body 可以帶 `filters`，照 3 驗證後存起來。前端拖拉版面、移除卡片時送的是整份設定，`filters` 原封不動帶回來；沒帶就是清掉。
- `POST /api/dashboards/{id}/charts`（加到既有儀表板）：保留原本的 `filters`。
- `GET /api/dashboards/{id}/data?filters=<JSON>`：`filters` 是 URL 編碼過的 JSON（3 的格式）。沒帶就是不篩選（不會自動套預設，前端自己帶）。用 GET 是因為這是讀取，也不用處理 CSRF。
  - 每張卡片的回傳多一個 `filterSkipped`：沒生效的篩選名稱清單，分類用欄位名稱，期間寫「期間」，例如 `["地區", "期間"]`。全部都生效時沒有這個欄位。
- `GET /api/jev/highlight/{id}?filters=<JSON>`：同樣的篩選。
- `GET /api/dashboards/{id}/filter-options`：能看這份儀表板的人都能用，用擁有者的身分載入資料（跟 `/data` 一樣）。

  ```json
  { "fields": [ { "field": "地區", "values": ["中區", "北區", "南區", "（空白）"] } ] }
  ```

  - 每張卡片的來源都算進來，取文字欄位，照畫面上的名稱合併，值取聯集。
  - 欄位照第一次出現的順序（卡片順序、schema 順序）；值照字串排序，「（空白）」排最後。
  - 聯集超過 200 個值的欄位不列。
  - 來源載入失敗、已刪除的卡片跳過，不報錯。
- 預覽（`POST /api/dashboards/preview/data`）不收篩選。

## 5. 後端

- `DashboardConfig` 多一個 `Filters filters`（record：`period`、`fields`，`fields` 每個是 `field`、`values`）。`DashboardRepository.Stored` 跟著多一個 `filters`，null 時不寫出來。
- 驗證寫在一個地方（例如 `Filters.problem()` 或 `DashboardService.requireValidFilters`），存檔和查詢參數共用 3 的訊息。
- `DashboardDataService.display`、`load` 多一個篩選參數：
  - 每張卡片轉換前，先照 2.2 過濾那個來源的資料列。同一個來源被好幾張卡片用，篩選結果可以不同（期間的日期欄位看卡片），所以對每張卡片各自過濾；不要改到 loader 共用的那份資料列。
  - 期間的起訖照 2.1 用 `Clock` 算（`DashboardDataService` 注入 `Clock`）。
  - `recent`（給 `/highlight` 用的那份）的 key 加上篩選：`擁有者:儀表板 id:篩選的標準 JSON`（沒有篩選時跟現在一樣）。
- `ChartData` 多一個 `filterSkipped`（`List<String>`，null 時 JSON 不輸出），`withSource`、`withLabels` 等複製方法要帶著它。
- `JevController.highlight` 收 `filters` 參數，傳給 `dashboardData.load`。
- `filter-options` 放在 `DashboardController`，資料由 `DashboardDataService` 算。

## 6. 畫面

### 6.1 篩選列

- 已存的儀表板，標題列和「依據」那幾行下面、格線上面，多一列篩選列。儀表板沒有任何卡片時不顯示。
- 由左到右：
  - 期間下拉選單（`v-select`，標籤「期間」，寬約 140px），選項 2.1。
  - 已經加的分類篩選，每個是一個可以關掉的 chip，文字「地區：北區、南區」，值超過 3 個時寫「地區：北區、南區等 5 個」。點 chip 打開跟「加篩選」同一個選單，可以改值。chip 的關閉鈕 `close-label` 是「移除「地區」篩選」。
  - 「加篩選」按鈕（`mdi-filter-plus-outline`，`variant="text"`）。已經有 3 個分類篩選時不顯示。
  - 有任何篩選時，「清除篩選」文字按鈕。
  - 擁有者才有：「存成預設」按鈕（`mdi-content-save-outline`，`variant="tonal"`）。目前的篩選跟存著的預設一樣時停用。
- 「加篩選」打開一個選單（`v-menu`，寬 320px）：
  - 第一次打開才呼叫 `filter-options`，結果留到換儀表板為止。載入中顯示進度條；失敗顯示錯誤訊息。
  - 「欄位」下拉選單，列出還沒加的欄位；沒有可以選的欄位時寫「這份儀表板沒有可以篩選的文字欄位」。
  - 「值」多選（`v-autocomplete`，`multiple`、`chips`、`closable-chips`），可以打字找。
  - 按鈕「取消」「套用」。沒選值時「套用」停用。
- 篩選一變（期間換了、套用、移除、清除），就用新的篩選重抓 `/data` 和 `/highlight`。重抓時照多來源 spec 10.3 的做法，卡片先留著舊資料，新資料回來再換；異常標註先清掉，等新的結果。
- 存成預設成功後，按鈕停用；失敗時錯誤顯示在儀表板上面的錯誤區（跟版面存檔失敗一樣）。存預設不重抓資料。

### 6.2 唯讀檢視

- 檢視者（分享 spec 7.8）看得到篩選列，可以改篩選，沒有「存成預設」。

### 6.3 載入順序

- 打開儀表板時，篩選先設成 `config.filters`，第一次 `/data` 就帶著它。
- 拖拉、縮放、移除卡片時存檔的是整份設定，`filters` 用存著的預設，不是目前臨時的篩選。
- 移除卡片走「只少了卡片就不重抓」的捷徑時，篩選沒變，捷徑照舊。

### 6.4 卡片

- `filterSkipped` 有東西時，卡片最下面加一行小字（樣式跟比率期間的說明一樣）：「沒套用篩選：地區、期間（這張圖的來源沒有這些欄位）」。
- 篩選後一列資料都沒有時，不畫空的圖，改成提示「篩選後沒有資料」。沒有篩選、本來就沒資料時寫「沒有資料」。明細表也一樣。

## 7. 測試

### 7.1 後端

- 每種期間的起訖（月初、月底、跨年的上季和上月）。
- 分類：一個值、多個值、「（空白）」、兩個分類同時、分類加期間。
- 照顯示名稱對到不同來源的不同欄位名稱；找不到時 `filterSkipped`。
- 期間用卡片的 `timeGrain` 欄位；沒有 `timeGrain` 時用第一個日期欄位；沒有日期欄位時 `filterSkipped` 有「期間」。
- 同一個來源兩張卡片用不同的日期欄位，各自過濾，互不影響。
- 比率：篩選後的期間對齊。
- 3 的每一條驗證訊息（存檔和查詢參數）。
- `filters` 存檔、讀回；加到既有儀表板時保留；`PUT` 沒帶時清掉。
- `filter-options`：只列文字欄位、照顯示名稱合併、聯集超過 200 不列、排序、跳過載入失敗的來源。
- `recent` 的 key 有篩選：先打一次有篩選的 `/data`，再打沒篩選的 `/highlight`，不會拿到篩選過的資料。
- 異常檢查用篩選後的資料。

### 7.2 前端

- 篩選列：期間選單、加篩選（呼叫 filter-options 一次）、chip 的文字和移除、清除、存成預設（只有擁有者、相同時停用）。
- 篩選一變就帶著新的篩選重抓 `/data`、`/highlight`；`api.dashboardData(id, filters)` 把篩選放進查詢字串。
- 打開儀表板時第一次 `/data` 帶著預設篩選。
- 拖拉存檔時帶的是預設篩選，不是臨時的。
- 卡片的 `filterSkipped` 說明、「篩選後沒有資料」。

### 7.3 瀏覽器（主 session 自己做）

- 一份兩個來源的儀表板（一個欄位叫 `region`、一個叫 `地區`，把 `region` 的顯示名稱設成「地區」）：選「地區：北區」，兩個來源的圖一起變；選一個只有一個來源有的欄位，另一個來源的卡片出現「沒套用篩選」。
- 期間選「上季」，折線圖只剩那三個月。
- 存成預設，重新整理還在；用檢視者帳號打開，看到預設、可以改、沒有「存成預設」。
- 篩選到沒資料，卡片顯示「篩選後沒有資料」。
- 每張圖對照 `/data` 的數字和畫面，自己讀截圖（不要只看資料）。

## 9. 不做

- 篩選放進網址（分享連結時帶著目前的篩選）。
- 自訂起訖日期、「近 N 個月」這類滾動期間。
- 數字欄位、日期欄位當分類篩選；數字範圍（例如金額大於 100 萬）。
- 每張卡片個別設定要不要套用篩選。
- 製圖頁預覽的篩選。

## 10. 決定（2026-10-07）

| 題目 | 選擇 | 沒選的 |
|---|---|---|
| 篩選存不存 | 擁有者可以存成預設，大家都能臨時改（使用者選） | 完全不存 |
| 篩選後的異常標註 | 照篩選後的資料重新判斷（使用者選） | 篩選時不顯示標註 |
| 多來源怎麼對欄位 | 照畫面上的欄位名稱（顯示名稱優先） | 只對原始欄位名稱 |
| 期間選項 | 日曆上的整段：本月、上月、本季、上季、今年、去年 | 滾動的近 N 個月、自訂起訖 |
| 期間的日期欄位 | 卡片的 `timeGrain` 欄位，沒有就用來源第一個日期欄位 | 讓使用者選日期欄位 |
| 分類篩選的數量 | 最多 3 個，值最多 200 個 | 不限 |
| 傳篩選的方式 | GET 查詢參數 `filters=<JSON>` | POST body（要處理 CSRF，沒登入的訪客也會用到） |
