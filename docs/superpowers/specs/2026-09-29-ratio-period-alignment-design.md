# JEV 儀表板：比率的期間對齊（設計）

日期：2026-09-29
前提：比率見 `docs/superpowers/specs/2026-09-28-ratio-metric-design.md`（B3），本文件只寫這次改變的部分。

## 1. 問題

B3 的比率是整段期間各自加總再相除。分子、分母的資料期間不一樣時，依分類算出來的比率會被稀釋。

對照來源上退貨只有 7～9 月、銷售有 1～9 月。「退貨率 依 product」把 1～6 月的銷售也算進分母，只有 1.3%～1.8%，按月看卻是 3.5%～4.3%。按季看也有同樣的問題：退貨如果從 8 月才開始，7 月的銷售會把 Q3 的退貨率拉低。

## 2. 規則

- 比率只算分子、分母都有資料的月份。整個來源一起看：找出分子有值的列從哪個月到哪個月，分母也一樣，兩段範圍取交集。
- 範圍外的列不算進比率，但它所在的那一組照樣留著位置。按月的圖 1～6 月還是空白；依產品的圖，某個產品只有範圍外的資料時，長條留空。
- 日期欄位怎麼選：有 `timeGrain` 的圖用 `x`；沒有的話，照 schema 順序逐一看日期欄位，分子的列和分母的列在這一欄都有日期，就用這一欄。對照來源上，只有一邊的來源對應到的日期欄位會跳過。
- 兩邊範圍一樣就不對齊，照 B3 的算法，沒有日期的列也照算。
- 有對齊時，沒有日期的列不算，因為不知道它落在哪個月。
- 來源沒有日期欄位，或找不到兩邊都有日期的欄位時，不對齊。
- 兩段範圍沒有重疊時，每一組都是空白。
- 只看範圍的第一個月和最後一個月，中間缺的月份不管。某個月真的沒有退貨時，不會被當成沒有資料。
- 一般來源和對照來源用同一套規則。

## 3. 資料和畫面

- `ChartData` 多一個 `ratioPeriod: { "from": "2026-07", "to": "2026-09" }`，只在有對齊時出現；`from` 比 `to` 晚代表兩段範圍沒有重疊。
- 卡片在圖下方加一行小字：
  - 「只算 2026-07～2026-09（分子、分母都有資料的月份）」
  - 只有一個月時：「只算 2026-07（分子、分母都有資料的月份）」
  - 沒有重疊時：「分子、分母的資料期間沒有重疊」
- 異常檢查和 JEV 分析都不用改。按月的圖數字跟以前一樣，異常檢查的結果也一樣。

## 4. 測試

- `UniversalTransformerTest`：依分類時只算重疊的月份，日期欄位跳過只有一邊有的；按月數字不變、範圍外的月份留著位置；按季只算重疊的月份；兩邊範圍一樣或沒有日期欄位時不對齊；沒有重疊時全部空白。
- `DashboardDataServiceTest`：日期欄位從 schema 傳進轉換器，`ratioPeriod` 會帶到 `display` 的結果。
- `ChartCard.test.js`：三種說明文字；沒有 `ratioPeriod` 時不顯示。
- E2E：用 `docs/superpowers/e2e/compare-datasource/` 建對照來源，加上退貨率，存一份儀表板，裡面有依產品、依區、按月、按季四張比率圖和一張一般的金額圖。實測依產品是 3.8%～4.1%，依區北區 4.4%、南區 3.4%，按月 7～9 月是 3.5%、4.3%、4.2%，按季 Q3 是 4.0%。四張比率圖下方都有說明，金額圖沒有。

## 5. 決定（2026-09-29 已確認）

| 項目 | 決定 | 另一種做法 |
|---|---|---|
| 對齊方式 | 只算兩邊資料期間重疊的月份 | 對照來源上比率不配分類欄位；數字不改，只在圖上加註 |
| 圖上標示 | 有排除期間時，圖下方加一行 | 不標示 |
