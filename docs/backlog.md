### JEV 差異化

原則照舊：數字由後端算，JEV 只負責選和打分數。

異常歸因和本期重點原本列在這裡，2026-10-01 移到「補齊」。Tableau Pulse 已經有 Top Drivers 和每個指標的 digest，Power BI 也有 Key Influencers，這兩項還是要做，只是算追上。

- P3 · 比率建議：看到「銷售金額」「退貨金額」這類欄位，建議加「退貨率」。現在比率要自己加。
- P3 · 一句話篩選：「只看北區上一季」，JEV 從欄位和相異值裡選出篩選條件。儀表板篩選器已經有了（2026-10-07），JEV 選出的條件直接套進篩選列就好，期間選項和 `filter-options` 的欄位、值都能沿用。JEV 不會產生文字，但這類句子的期間和分類條件都能拆成封閉選項，不用 LLM（2026-10-01 對照 TypeSafe 官方文件）。期間用一題 Choice，從「不限、上月、本季、上季、今年、去年」這類固定選項裡挑，實際是哪幾個月由後端照今天的日期算，跟異常檢查判斷「已結束期間」用同一套。分類先用一題 Noul 問「使用者是不是只想看欄位「地區」的某些值？」，再對每個相異值各問一題 Noul（「使用者想看「北區」嗎？」），多選也能處理。官方 Function calling cookbook 也是這樣做，每個股票代號一題 Noul，期間從固定選項挑。句子裡一字不差寫出某個相異值時，後端直接比對字串就好，不必問 JEV；比對在後端做，敏感欄位也適用。JEV 負責的是「北部」「North」這種換了說法的情況。直接交給 JEV 做不到的有三種：任意數字，例如「金額超過 100 萬」「前 5 名」「近 45 天」，官方建議數字留給程式處理，可以照 Pre-parsed value extraction 的做法，先用正規表示式抓出候選，再讓 JEV 挑；交集和排除，例如「北區或中區，但不含台中」；相異值上千個的欄位（例如客戶名稱），每個值一題會超過單次請求 64k token 的上限，要先用字串比對縮小候選。Noul 沒有 confidence，只能拿 noul 值本身當門檻。異常檢查的門檻是照 jev-1.13.0 調的，篩選要拿真實的中文句子另外實測。
